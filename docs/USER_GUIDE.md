## 1. Getting Started

When you first launch ClipFlow, the app opens at `http://localhost:4401`. You land on the **Dashboard**, the central hub for everything you do.

The interface has two main areas:

- **Sidebar** (left) -- Navigation links to Dashboard, Editor, ClipGen, Templates, Batch, History, and Settings. A connection indicator at the bottom shows whether the real-time WebSocket link to the server is active.
- **Main content area** (right) -- Changes depending on the page you are on.

The Dashboard shows a drag-and-drop upload zone at the top and a list of your recent projects below it. If you have no projects yet, you will see a prompt to upload your first video.

---

## 2. Uploading a Video

### How to upload

You have two options on the Dashboard:

- **Drag and drop** a video file onto the upload zone.
- **Click** the upload zone to open a file picker.

### Supported formats

| Format | Extension |
|--------|-----------|
| MP4    | `.mp4`    |
| MOV    | `.mov`    |
| WebM   | `.webm`   |
| AVI    | `.avi`    |

Maximum file size: **500 MB**.

### What happens after upload

1. The file is uploaded to the server and stored in the `data/uploads/` directory.
2. FFmpeg extracts metadata from the video (resolution, duration, codec, frame rate).
3. A thumbnail is generated and displayed on your project card.
4. A new project is created with status **draft**.

You will see a progress bar during the upload. Once complete, the Dashboard shows the video metadata card with duration, resolution, and file size.

## 3. Transcribing

After uploading, the next step is transcription.

1. Open your project in the **Editor** (click "Open in Editor" on the Dashboard, or navigate to Editor from the sidebar).
2. Click the **Transcribe** button.

ClipFlow uses **WhisperX** to process the audio. Here is what happens behind the scenes:

1. FFmpeg extracts the audio track from your video and saves it to `data/audio/`.
2. The WhisperX Python sidecar processes the audio file.
3. WhisperX produces **word-level timestamps** -- every single word gets a precise start and end time.
4. If you have a HuggingFace token configured, speaker diarization identifies different speakers.

Progress updates are streamed to the app in real time via **WebSocket**, so you can watch the transcription advance without refreshing the page.

When transcription is complete, the project status changes to **transcribing > done** and the full text, word timestamps, and segments are stored in the database.

## 4. AI Analysis

Once transcription is finished, you can run AI analysis.

1. In the Editor, click **"Analyze with AI"**.
2. Claude (via the Anthropic API) receives the transcription and generates a structured scene plan.

The AI analysis produces:

- **Scene plan** -- A sequence of scenes, each with a type (hook, content, transition, b-roll, CTA, outro), time range, and description.
- **Hook analysis** -- How effective the opening is at grabbing attention.
- **CTA analysis** -- Suggestions for calls to action.
- **Engagement score** -- A rating from 0 to 100 predicting how engaging the content is.
- **Suggested cuts** -- Where to trim for maximum impact.
- **Suggested effects** -- Visual effects that match the content.

After analysis, scenes appear in the Scene Panel and on the Timeline, ready for editing.

## 5. Editing

The Editor page is where you refine your video. It is divided into four areas:

```
+-------------+-------------------+-------------+
| Scene Panel |   Video Preview   |  Inspector  |
|             |                   |             |
|  (list of   |  (live Remotion   | (properties |
|   scenes)   |   composition)    |  of selected|
|             |                   |    scene)   |
+-------------+-------------------+-------------+
|                  Timeline                      |
|  (scene clips + caption track + ruler)         |
+------------------------------------------------+
```

### Scene Panel (left)

Lists all scenes generated by AI analysis. Each scene card shows its type (hook, content, CTA, etc.), time range, and description. Click a scene to select it.

### Video Preview (center)

A live Remotion preview of your composition. Plays the video with captions, effects, and transitions applied in real time.

### Inspector (right)

When you select a scene, the Inspector shows its editable properties:

- **Type** -- hook, content, transition, b-roll, CTA, outro
- **Time range** -- Start and end timestamps (adjustable)
- **Description** -- Text describing the scene content
- **Effects** -- Visual effects applied to this scene
- **Transitions** -- Transition in and transition out

### Timeline (bottom)

The Timeline shows a horizontal ruler with time markers, scene clips on a track, and a caption track below. You can:

- Drag scene edges to adjust duration.
- Click on the caption track to select individual words.
- View word-level timing in the caption editor.

### Caption editing

Select a word on the caption track to open the **Word Timing Adjust** panel, where you can:

- Edit the word text.
- Adjust start and end times (in seconds).
- See confidence scores from WhisperX.
- View surrounding context.

### Caption Style Picker

Choose from four primary caption animation styles:

| Style | Description |
|-------|-------------|
| **Highlight** | The active word glows with a highlight color |
| **Karaoke** | Color fill reveals from left to right as words are spoken |
| **Pop** | Words bounce into view with a spring animation |
| **Glow** | Neon glow effect around the active word |

Additional styles available: None (static text), Typewriter, and Bounce.

You can also configure font family, font size, font weight, text color, highlight color, stroke, background, and position (top, center, bottom).

## 6. Templates

Navigate to **Templates** from the sidebar to access the template gallery.

### Built-in templates

ClipFlow includes 6 built-in templates, one for each content niche:

| Niche | Pacing | Hook Strategy | Caption Style | CTA |
|-------|--------|---------------|---------------|-----|
| **Fitness & Health** | Fast | Before/After | Pop | Follow for more |
| **Tech & SaaS** | Medium | Problem Statement | Highlight | Link in bio |
| **Food & Recipe** | Medium | End Result First | Karaoke | Save recipe |
| **Education & Tutorial** | Slow | Curiosity Gap | Highlight | Follow for tips |
| **E-commerce & Product** | Fast | Urgency | Glow | Shop now |
| **Podcast & Talking Head** | Dynamic | Controversial Quote | Highlight | Full episode link |

### Filtering

Use the niche selector at the top of the Templates page to filter templates by category.

### Applying a template

1. Click **Preview** on a template card to see its configuration.
2. Click **Apply to Project** to apply the template's settings to your current project.

When you apply a template, the following are set on your project: caption style, effects, transitions, color palette, hook configuration, CTA configuration, and pacing.

### Creating custom templates

Click **"Create Custom"** to open the template creation form. You can configure:

- **Name** -- A descriptive name for your template.
- **Niche** -- Select a niche to pre-fill defaults, or leave blank for a generic template.
- **Pacing** -- slow, medium, fast, or dynamic.
- **Hook strategy** -- How the opening grabs attention (before/after, problem statement, curiosity gap, urgency, controversial quote, end result first).
- **CTA style** -- The call to action approach (follow for more, link in bio, save recipe, shop now, follow for tips, full episode link).
- **Caption style** -- Default animation for captions.
- **Effects** -- Default visual effects.
- **Transitions** -- Default transition types.
- **Color palette** -- Brand colors (primary, secondary, background).
- **Composition** -- The Remotion composition configuration.

Custom templates appear alongside built-in ones and can be applied to any project.

## 7. Exporting

When your edit is ready, click the **Export** button in the Editor to open the Export Dialog.

### Choosing formats

Select one or more export formats:

| Format | Aspect Ratio | Resolution | Max Duration | Platform |
|--------|-------------|------------|-------------|----------|
| Instagram Reel | 9:16 | 1080x1920 | 90s | Instagram |
| TikTok | 9:16 | 1080x1920 | 180s | TikTok |
| Feed Square | 1:1 | 1080x1080 | 60s | Instagram |
| Feed Portrait | 4:5 | 1080x1350 | 60s | Instagram |
| Story | 9:16 | 1080x1920 | 60s | Instagram |

### Quality presets

| Preset | CRF | Speed | Use case |
|--------|-----|-------|----------|
| **Draft** | 28 | Fastest | Quick preview |
| **Standard** | 23 | Balanced | General use |
| **High** | 18 | Slower | High-quality posts |
| **Maximum** | 15 | Slowest | Best possible quality |

### Rendering

1. Click the **Export** button (shows the number of selected formats).
2. Remotion renders the composition using Chromium in the background.
3. A real-time progress bar shows the render status for each format.
4. When complete, the status changes to **Export Complete**.

### Downloading

Each completed render shows a **Download** button. Click it to download the rendered MP4 file. Rendered files are stored in `data/renders/`.

You can also find past exports on the **History** page.

## 8. ClipGen

ClipGen is a tool for extracting viral-worthy clips from longer videos. Navigate to **ClipGen** from the sidebar.

### How it works

1. Select a project that already has a transcription.
2. Configure the analysis parameters:
   - **Target platform** -- TikTok, Instagram Reels, or YouTube Shorts.
   - **Target duration** -- How long each clip should be (e.g., 30 seconds).
   - **Number of clips** -- How many clip suggestions to generate (e.g., 5).
   - **Tone** -- The desired tone (energetic, calm, dramatic, humorous, etc.).
   - **Niche** -- Content category for context-aware suggestions.
   - **Custom instructions** -- Any additional guidance for the AI.
3. Click to start the analysis.

### Reviewing suggested clips

Claude AI analyzes the full transcription and suggests the most engaging segments. Each suggested clip includes:

- **Title** -- A descriptive name.
- **Time range** -- Start and end timestamps in the original video.
- **Hook sentence** -- The opening line that grabs attention.
- **Hook score** -- A rating of how strong the hook is.
- **Emotional tone** -- The dominant emotion of the segment.
- **AI reasoning** -- Why this segment was selected.
- **Suggested hashtags** -- Platform-appropriate hashtags.

### Accepting or rejecting clips

Each clip card has actions to:

- **Accept** (select) -- Marks the clip for rendering. You can then edit it further or send it straight to export.
- **Reject** -- Removes the clip from the active list.

Accepted clips can be rendered individually with their own caption style, animation, aspect ratio, and quality settings.

## 9. Batch Processing

Navigate to **Batch** from the sidebar to process multiple videos with the same settings.

### Creating a batch job

1. Click **"New Batch"**.
2. Enter a name for the batch job.
3. Provide video file paths (one per line).
4. Optionally select a template and caption style to apply to all videos.
5. Choose the export formats.
6. Click **Create**.

### Running the batch

- Click **Start** to begin processing. Videos are processed sequentially: upload, transcribe, analyze, render.
- Click **Pause** to stop processing after the current video finishes. No work is lost.
- Click **Resume** to continue from where you left off.

Each batch job card shows:

- Total number of videos.
- How many are completed.
- How many failed (with error messages).
- Current status: Pending, Processing, Paused, Complete, or Error.

Failed videos do not stop the batch. Processing continues with the next video, and you can review errors afterward.

## 10. Settings

Navigate to **Settings** from the sidebar.

### Available settings

| Setting | Description | Default |
|---------|-------------|---------|
| **WhisperX Model** | The transcription model to use. Larger models are more accurate but slower. | `large-v3` |
| **Default Language** | Language for transcription. Set to auto-detect or choose a specific language. | Auto-detect |
| **Export Quality** | Default quality preset for exports. | Standard |

Changes are saved immediately when you modify a value.

## 12. Changing Language

ClipFlow supports two languages:

- **English** (default)
- **Portugues (pt-BR)**

To switch languages, use the **language switcher** in the sidebar. The entire interface updates immediately -- all labels, buttons, messages, and placeholders are translated.

Both language files are located in `packages/app/src/locales/` (`en.json` and `pt-BR.json`).
